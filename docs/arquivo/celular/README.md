# Arquivo — apps de celular

Plano dos apps de Android e iOS do Duo (várias contas do mesmo serviço em
contêineres web isolados e, no Android, um motor nativo por virtualização).
Descontinuado em 2026-10-09, quando o Duo passou a ser só o app de Mac
([`mac/`](../../../mac), spec em [`spec/MAC.md`](../../spec/MAC.md)). Guardado
para consulta; **não é o produto**. Links destes arquivos para `produto/`,
`design/` e `publicacao/` apontam para documentos que hoje descrevem o app de
Mac.
